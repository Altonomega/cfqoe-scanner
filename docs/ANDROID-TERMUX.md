# اجرای CFQoE Scanner روی Android با Termux

این نسخه از Android/Termux روی arm64 و محیط‌های Android x64 پشتیبانی می‌کند و به root نیاز ندارد.

## نصب با یک دستور

```bash
pkg update -y && pkg install -y git && git clone https://github.com/Altonomega/cfqoe-scanner.git && cd cfqoe-scanner && bash install-termux.sh
```

پروژه را داخل `$HOME` نگه دارید، نه `/sdcard`، `/storage` یا Download.

## اجرای دفعات بعد

```bash
cd ~/cfqoe-scanner
./start-cfqoe.sh
```

## به‌روزرسانی

```bash
cd ~/cfqoe-scanner
git pull
bash install-termux.sh
```

## چک‌لیست دستی: از نصب تا ادامه اسکن

از نسخه 0.9.0 سطح پیش‌فرض برنامه **رابط وب** است؛ مراحل زیر همان مسیر را از اول تا آخر می‌روند.

1. **نصب:** دستور یک‌خطی بالا را اجرا کنید و صبر کنید نصب Xray و بررسی سیستم تمام شود.
2. **اجرا:** `./start-cfqoe.sh` را بزنید. مرورگر با رابط وب باز می‌شود؛ اگر خودکار باز نشد، **لینک خصوصی** چاپ‌شده در ترموکس را کپی و در مرورگر باز کنید.
3. **هشدار اندروید:** روی این دستگاه، اپ‌های دیگر هم می‌توانند به نشانی محلی اسکنر برسند؛ لینک خصوصی تنها محافظ آن است. لینک را با کسی به اشتراک نگذارید و وقتی کارتان تمام شد، رابط وب را ببندید (خروج از برنامه کافی است).
4. **وارد کردن کانفیگ:** در رابط وب وارد `VLESS Configuration` شوید، لینک VLESS را بچسبانید و ذخیره کنید. ورودی نامعتبر همان‌جا رد می‌شود و علتش نمایش داده می‌شود.
5. **بررسی سیستم:** `System Check` را اجرا کنید؛ خروجی باید `android-arm64` و Xray موجود را نشان دهد.
6. **اولین اجرا:** `Quick Scan` را بزنید؛ پیشرفت به‌صورت زنده در همان صفحه دیده می‌شود و نتیجه در `Best IPs` می‌آید.
7. **توقف امن:** وسط هر اسکن می‌توانید دکمه توقف در رابط وب را بزنید (در منوی ترمینال: `Q` یا `Ctrl+C`). توقف امن است و برای Hard Deep Scan چک‌پوینت ذخیره می‌شود.
8. **ادامه:** برای ادامه Hard Deep Scan از دکمه ادامه در رابط وب استفاده کنید (در منوی ترمینال: گزینه `5` یعنی `Resume Hard Scan`).
9. **اسکن طولانی:** لانچر خودش `termux-wake-lock` می‌گیرد؛ بااین‌حال Battery Optimization ترموکس را روی `Unrestricted` بگذارید تا اندروید وسط اسکن برنامه را نبندد (بخش «جلوگیری از قطع اسکن» پایین).

منوی ترمینال هم با `cfqoe menu` در دسترس است و همه همین کارها را دارد.

## رفتار اسکن‌ها

- Quick و Full در هر بار اجرا یک seed تازه می‌سازند، پس sampleها نباید دائماً یکسان باشند.
- Quick فقط یک sample کوچک و Full یک sample بزرگ‌تر است؛ هیچ‌کدام قرار نیست کل catalog را در یک اجرا بررسی کنند.
- Hard Deep Scan کل catalog را بلوک‌به‌بلوک (بلوک = ‎/24‎) پیمایش می‌کند: اول در هر بلوک چند probe آزمایشی (primer) می‌زند، بعد بودجه probe را روی بلوک‌های امیدوارکننده متمرکز می‌کند و بلوک‌های ناهمگون را به دو نیم تقسیم (split) می‌کند.
- Hard Scan روی Termux به‌طور پیش‌فرض 6 IP را هم‌زمان screen می‌کند و بودجه probe آن ۴۰٬۰۰۰ است (دسکتاپ: ۷۲٬۰۰۰).
- sweep اولیه برای سرعت یک round دارد و 12 finalist برتر قبل از tunnel با roundهای کامل دوباره بررسی می‌شوند.
- Hard Scan چک‌پوینت می‌سازد و پس از توقف یا بسته‌شدن برنامه، از همان‌جا ادامه پیدا می‌کند.

جزئیات فنی: [HARD-DEEP-SCAN.md](HARD-DEEP-SCAN.md)

## جلوگیری از قطع اسکن

لانچر به‌صورت خودکار `termux-wake-lock` می‌گیرد و پس از خروج آزاد می‌کند. برای اسکن طولانی:

- Battery Optimization را روی Unrestricted قرار دهید.
- در صورت امکان Termux را در Recent Apps قفل کنید.
- اگر Android برنامه را بست، `Resume Hard Scan` را اجرا کنید.

## بهینه‌سازی موبایل

- Hard concurrency اولیه 6 است تا فشار CPU و حرارت کنترل شود.
- checkpoint در نصب تازه هر 10 IP ذخیره می‌شود.
- progress bar با عرض صفحه تطبیق پیدا می‌کند.
- گزینه‌های 9 و 10 روی صفحه باریک خروجی چندخطی دارند.
- همه خروجی‌ها زیر منوی فعلی باقی می‌مانند تا کاربر Enter بزند.

اگر گوشی بیش از حد گرم شد، از `Scan Settings` مقدار `Hard concurrent IPs` را به 3 یا 4 کاهش دهید.

## مصرف باتری و اینترنت

Quick سبک‌تر است. Full و Hard زمان و داده بیشتری مصرف می‌کنند. مرحله tunnel شامل مرور وب و دریافت segmentهای HLS واقعی است.

## خطاهای رایج

### `Unsupported platform: android`

```bash
cd ~/cfqoe-scanner
git pull
bash install-termux.sh
```

### `Permission denied`

```bash
cd ~/cfqoe-scanner
chmod +x xray/xray start-cfqoe.sh
./start-cfqoe.sh
```

### Android برنامه را وسط Hard Scan بست

برنامه را دوباره اجرا کنید و از رابط وب (یا گزینه `Resume Hard Scan` در منوی ترمینال) ادامه دهید؛ اسکن از آخرین چک‌پوینت برمی‌گردد.
